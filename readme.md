## Project Description

**Goals:** work with datasets using Pandas, build dashboards with Streamlit, and visualize data through plots.

**Assignment:** use the `pl01_dataset.zip` file (available in the **Extras** folder on Teams), which contains multiple Formula 1-related files. The project must include:

- At least **8 analyses**, including plots, tables/dataframes, and other relevant elements;
- Data processing **only** on the files needed for the defined analyses: imports, merges, exploratory data analysis, and other relevant operations;
- A **Streamlit** dashboard that is navigable and intuitive, using multiple pages or another navigation approach;
- Printing data (full or partial) using `table`, `dataframe`, or similar;
- Plots for each analysis (multiple plots per analysis are allowed), using Matplotlib, Seaborn, Altair, Plotly, or another suitable tool;
- Multimedia elements and properly organized layouts using columns, containers, or other Streamlit components.
